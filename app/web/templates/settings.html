Web UI access

By default every visitor must sign in. On a trusted network you can let visitors use this UI without a password, with the role chosen below; signing in still gives a user their own role. Open access is honoured only when the UI is reached by IP address, localhost or this machine's host name (protection against DNS rebinding — other names still ask for a login); behind a reverse proxy, have it pass the original name in X-Forwarded-Host, or keep login on. Other cluster nodes are only shown and managed after signing in, and the REST API always needs its token.
